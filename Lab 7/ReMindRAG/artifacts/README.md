# Artifacts Directory

This directory is intended to store the persistent outputs generated by the ReMindRAG system. 

## Recommended Contents

- **Knowledge Graphs**: Serialized JSON or pickle files of extracted entities and relationships.
- **Evaluation Results**: Metrics and performance reports generated from the `eval/` scripts.
- **Visualizations**: Exported images or HTML visualizations of the knowledge graph and traversal paths.
- **ChromaDB Exports**: Snapshots of the vector database for portability.

By consolidating these files here, the system's "memorization" and "evaluation" outputs remain organized and separate from the source code.
