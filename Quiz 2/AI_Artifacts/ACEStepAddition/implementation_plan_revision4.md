# Goal: Radically Improve ACE-Step Generation Quality (Fixing Garbled Noise)

After a deep architectural review of the ACE-Step v1.5 SFT pipeline, I have identified the exact root cause of the "garbled noise" issue. 

ACE-Step is a **two-stage hybrid architecture**:
1. **Language Model (LLM)**: Parses the text prompt and predicts discrete semantic tokens (`audio_codes`) that structure the composition, rhythm, and melody.
2. **Diffusion Model (DiT)**: Generates the actual acoustic latents, conditioned on BOTH the text prompt AND the `audio_codes` generated by the LLM.

**The Root Cause**:
To save VRAM and latency, we previously disabled the `thinking` parameter (`thinking=False`) and skipped loading the `LLMHandler` because we incorrectly assumed the Gemini PromptTranslator's output would be sufficient to guide the DiT. However, this caused the DiT to receive an empty array for `audio_codes`. Because the ACE-Step DiT cross-attention layers are heavily trained to rely on these semantic `audio_codes` for structure, starving the DiT of these codes causes the latent diffusion to completely derail, resulting in white static noise and terrible FAD scores (26-33).

## Proposed Changes

We will restore the dual-stage architecture by loading and passing the `LLMHandler` in the `AceStepMusicGenerator`. Since we are running on a CPU-bound system, we will explicitly configure the LLM to run on the CPU with PyTorch.

### `music_generator.py`

#### [MODIFY] `music_generator.py`
- Initialize `LLMHandler` within `AceStepMusicGenerator.initialize()`.
- Load the language model (`acestep-5Hz-lm-1.7B` or default) onto the CPU.
- Enable `thinking=True` inside `GenerationParams`.
- Pass `self.llm_handler` into the `acestep.inference.generate_music` call instead of `None`.

```python
    def initialize(self):
        if not self.is_initialized:
            print("Initializing ACE-Step SFT model...")
            import sys
            import os
            # Ensure acestep is in path
            current_dir = os.path.dirname(os.path.abspath(__file__))
            if current_dir not in sys.path:
                sys.path.insert(0, current_dir)
            
            from acestep.handler import AceStepHandler
            from acestep.llm_inference import LLMHandler
            
            self.dit_handler = AceStepHandler()
            self.llm_handler = LLMHandler()
            
            # AceStep natively supports VRAM offloading
            self.dit_handler.initialize_service(
                project_root=current_dir,
                config_path="acestep-v15-sft",
                device=self.device,
                offload_to_cpu=True,
                offload_dit_to_cpu=True
            )
            
            print("Initializing ACE-Step LLM...")
            # Init the LLMHandler on CPU
            from acestep.model_downloader import get_checkpoints_dir
            ckpt_dir = str(get_checkpoints_dir())
            self.llm_handler.initialize(
                checkpoint_dir=ckpt_dir,
                lm_model_path="acestep-5Hz-lm-1.7B", 
                backend="pt",
                device=self.device,
                offload_to_cpu=True,
                dtype=torch.float32
            )
            self.is_initialized = True
```
