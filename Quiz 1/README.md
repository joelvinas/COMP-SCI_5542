# Resilient Shelf: Controlled Retail Layout Visualization

This repository contains the solution for the CS 5542 Quiz Challenge, Option 2 (Interior Design/Retail Space Visualization). 

## Project Overview
The "Resilient Shelf" system transforms structured inventory data and room constraints into optimized retail layout visualizations using Controlled Image Generation.

## File Structure
- `retail_design_pipeline.py`: Google Colab-ready Python script that integrates the components:
  - **Data-to-Prompt Engine**: Converts JSON metadata to structured prompt templates.
  - **Stable Diffusion Pipeline**: Uses `diffusers` with `StableDiffusionControlNetPipeline`.
  - **Control Mechanism**: Implements ControlNet (Canny) to maintain shelf structural layout.
  - **Evaluation Module**: A framework to provide Baseline vs Improved comparisons, failure analyses, and alignment/consistency checks.

## Included Functionality
- **Structured vs Naive Comparison**: Generating images using a simple prompt vs. a prompt generated by the Data-to-Prompt Engine.
- **Failure Analysis**: Includes a generated failure case (high guidance scale and conflicting prompts) to demonstrate where the system breaks down.
- **Consistency**: Uses a fixed random seed and controlnet conditioning to preserve structure while changing "Substitute Products".
- **Dataset**: Automatically pulls a sample layout representing our custom real-world retail layout constraints (proxy for SUN RGB-D).

## Use of AI Tools (Disclosure)
- **Large Language Models (LLM)**: Used an LLM to scaffold the Python boilerplate for the Diffusers pipeline and structure the repository components. It also assisted in writing proper prompt templates for structured inference.
- **Copilot Tools**: Assisted in code completion, particularly in the `evaluate_generation` evaluation module and OpenCV Canny edge detection implementations.

## Bonus: Multimodal Extension
This system can be logically extended using **Runway/Pika** to transform the static generated retail shelves into 1-2 second video walkthroughs and **ElevenLabs** to narrate the spatial optimization choices over the video! The current code serves as the core spatial layout generator feeding directly into those text-to-video capabilities.
